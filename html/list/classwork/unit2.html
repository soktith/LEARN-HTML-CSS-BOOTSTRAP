Definition List

HTML
HTML stands for HyperText Markup Language, which is the standard code used to create and structure web pages.
CSS
CSS stands for Cascading Style Sheets. It is a declarative stylesheet language used to describe the presentation, layout, and visual formatting of a document written in HTML or XML. Along with HTML and JavaScript, CSS is one of the foundational core technologies of the World Wide Web
